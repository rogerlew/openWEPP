# Canopy Phenology References

This directory preserves the evidence admitted by the openWEPP canopy
phenology assurance campaign.

- `elliot_2026/` contains William J. “Bill” Elliot’s commissioned report and
  delivered WEPP management files. The project paid for this work and has
  permission to redistribute these exact files.
- `literature/` contains independent literature, a searchable transcription of
  a scanned report, and source-native Hubbard Brook synthesis-book material.
Copyright and reuse conditions remain those of each source; inclusion here
does not relicense third-party work.

Bill Elliot's commissioned files are cleared by project permission. On
2026-07-26 the operator also confirmed redistribution permission for the
independent literature and Hubbard Brook source set. The authority record is
`docs/work-packages/20260726-canopy-cal-01-source-target-ledger-001/artifacts/publication-rights-register.md`
and source-native copyright/license notices remain controlling.

The source files are retained byte-for-byte. Filenames alone were normalized.
The campaign’s provenance, target classifications, and source limitations are
recorded in
`docs/work-packages/20260726-canopy-cal-01-source-target-ledger-001/artifacts/`.

All PDFs are routed through the repository’s Git LFS rule.
