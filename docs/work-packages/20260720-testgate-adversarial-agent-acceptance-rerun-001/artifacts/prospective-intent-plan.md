# Prospective Intent Plan

Evidence class: `Static`.

Boundary: local documentation-only procedural acceptance.

| Gate | Reason | Invalidation |
| --- | --- | --- |
| Instruction/status/write-set intake | Establish authority and preserve unrelated work. | Rerun only if repository or controller state changes. |
| Baseline reuse reconstruction | Prove broad integrated closure remains current. | Any governed non-document input change invalidates reuse and holds execution. |
| Initial diff hygiene | Observe the seeded in-scope whitespace fault. | Expected to fail once before cause-only repair. |
| Hygiene-only rerun | Prove the exact fault is repaired and sentinel unchanged. | Rerun only after package-path edits that affect path/diff hygiene. |
| Planner binary provenance/build | Supply the real local planner to the helper. | Build once only if exact current provenance is unavailable. |
| Local TESTGATE execution | Exercise real intent/terminal planning, one selected documentation node, execution, and independent receipt verification. | Run once from a fresh artifact root after the sentinel is removed and pre-receipt evidence stabilizes. |
| Dual review and verification | Challenge governance fidelity, test economy, exact diff, and receipt truth. | Accepted findings invalidate only their affected surfaces. |
| Final Markdown/path hygiene | Validate post-receipt evidence, review records, prompt archival, and disposition. | Last documentation mutation requires this cheap final gate. |

Explicitly not selected: separately invoked Nextest, Clippy, coverage, CRAP,
cargo-deny, comparator, campaign certification, release qualification,
assurance suites, GitHub actions, forest1 work, manual dispatch, or timed/count
observation.

Gate non-deferral: all selected gates close inside this package. A baseline
input change is a predeclared `HOLD-BASELINE-INVALIDATED` boundary, not a reason
to broaden this package after execution begins.
