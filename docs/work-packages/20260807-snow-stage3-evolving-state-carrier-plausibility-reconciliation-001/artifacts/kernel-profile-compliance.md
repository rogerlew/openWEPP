# Kernel Profile Compliance

Static: Phase-A applicability disposition.

The package changes characterization authority and contract-derived tests only.
It does not change production kernel behavior or runtime projection semantics.
The kernel-process implementation profile is therefore `NOT_APPLICABLE` to a
production change. Contract schema, variables/units, guard mapping, obligations,
test vectors, gap posture, and binding exposure remain applicable and must pass
the contract gate.
