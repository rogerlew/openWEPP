# Diffuse sky view derived from effective canopy cover

The solid blue curve is the EB-02 contract translation from the native canopy
model's effective overhead cover to the fraction of the sky hemisphere seen by
the snow surface. The dashed orange line is the tempting but rejected shortcut
that treats vertical plan-view gap as hemispherical sky view.

The distinction matters most under intermediate and dense cover. Diffuse
radiation travels through a range of oblique path lengths, so it is attenuated
more strongly than a vertical ray. EB-02 represents that geometry by
eliminating the common Beer-law canopy state between FSM2's vertical and
diffuse transmission equations:

```text
vertical gap = 1 - C = exp(-k_ext VAI_eff)
diffuse sky view = exp(-1.6 k_ext VAI_eff) = (1-C)^1.6
```

This route adds no user coefficient. LAI and the native structural-cover floor
already contribute to the daily effective cover state and are not added again.
Canopy height remains useful descriptive state but is not an independent term
in this homogeneous one-layer radiative translation.

Figure type: deterministic analytical response, not observations or a fitted
relationship.

Source: `SC-SNOWENERGY-001`, `REF-SNOWENERGY-FSM2`; generated by
`tools/execute.py`.

Accessibility: the horizontal axis is effective canopy cover from zero to one;
the vertical axis is diffuse sky view from zero to one. Both curves start at
one under open sky. The canonical curve falls below the direct-gap line and
approaches zero more rapidly as cover increases.
