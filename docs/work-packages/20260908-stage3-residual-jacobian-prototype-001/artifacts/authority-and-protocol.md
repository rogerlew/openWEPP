## Mathematical target and exact initial coverage

Target `r(x;u,b0)` is the canonical normalized covered residual evaluated from
the complete validated input `u` and only the existing frozen root/wet/ground
water branches `b0`. `D=10N+3+S`; exact coordinate and residual orders are in
the v33 numerical-method amendment. Normalizers remain functions of `x`.

Initial J block: all active dry-stem columns `j=10o+9`, arbitrary N/S. Complete
affected rows are positive-area component rows at `i!=o` through upward/downward
longwave propagation and normalization; own stem through direct emission and
sensible heat; same-layer sun/shade/wet rows are exact zero; shared heat through
sensible heat/normalization; and ordinary
non-represented-snow ground energy through longwave/normalization. Stage-3
ground/soil anchors and every other row are independent exact zeros. Zero-area
stem coordinates remain canonical identity columns.

Existing validation rejects nonfinite `dry_stem`; supported entry requires
positive executed `dry_stem`, interior finite stem temperature, same
validated base/generation/order/frozen branches, and a certified interval that
crosses no physical branch, abs zero, max tie, or maximizer change. This is
decided before column execution. Post-entry arithmetic/integrity failure returns
typed failure with no FD retry. A private single-assembly capability prevents
stale, foreign, mutated and second use.

Primary representation: explicit analytic tangents through shared canonical
longwave, stem sensible-heat, raw residual and normalization operands. It must
not duplicate approximate primal physics. If factoring shared nodes changes
ordinary primal evaluation, a separately identified mechanical A-to-Ax control
must pass bit-identical residual/error/full-result evidence and its cost is
reported separately.

Only eligible expansion: paired active sun/shade leaf-temperature columns. It
requires a reviewed implicit derivative of the converged leaf `ci` equation,
finite inner-residual error term, gas/VPD/Medlyn branch admission, and updated
complete dependencies. Wet/routing, hydraulic/beta, shared air, ground and soil
blocks are excluded.

## Frozen oracle and corpus

The oracle independently calls only canonical primal residuals. It independently
enumerates all affected/zero rows; R's graph is a cross-check only. For each
entry it samples nine `2^k h0` scales (`k=-4..4`) and applies the exact v33
consecutive-triple ratio, tie-break and Richardson algorithm. Baseline support
is frozen before J. It computes v33 U and applies the frozen
`8U + 2e-7 K^-1 + 5e-5 relative` derivative bound. It also performs at least
the exact eight direction sequence, `t0`, six halvings and per-row floor, with
second-order contraction `[3.2,4.8]`, analytic sensible/Stefan-Boltzmann sign/unit checks and
one omission-sensitive perturbation per cross-occupancy edge. Baseline-unresolvable
entries are frozen unsupported; admitted candidate disagreement fails.

Freeze before J comparison reconstructible states covering N=2/S=6 early/late
potential and fixed-final sweeps, smooth interiors, exact/near stem bounds,
positive/zero component areas, longwave cross-occupancy, represented-snow
identity anchors, ordinary ground coupling when lawfully available, successful
solves and natural rejection/limit cases. Add an existing different-cardinality
case where available. Each record binds configuration, forcing/support/caps,
water/litter/snow/soil state, `u`, `x`, `b0`, base residual and lifecycle IDs.

Expected-red tests are added to the detached A source before candidate code and
must demonstrate missing derivative capability/assembly/counters while the
ordinary baseline tests remain green. Required negatives: mask/order/cardinality,
closed/tie/nonsmooth structural inapplicability, nonfinite/domain, stale/foreign /
mutated/second-use, support/cap change and no-recovery error propagation.

## Solver/regime and consumer boundary

This package adds no production-reachable solver. A and detached J retain the
single currently selected covered-column solver/controller per preselected
regime and its canonical FD backend for unsupported columns. The known v33–v57
production chain quarantine is neither expanded nor claimed resolved. Real path:
Stage3 native terminal carrier -> validated covered map ->
`solve_covered_column_impl` -> hybrid Jacobian -> Newton update -> accepted
covered result -> existing owner envelope/publication. Shadow-only execution
cannot close consumer participation.
