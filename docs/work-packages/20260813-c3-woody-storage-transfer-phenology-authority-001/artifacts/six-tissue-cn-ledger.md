# Six-Tissue C/N Ledger

Static: the exact owner set is leaf, fine root, live stem, dead stem, live
coarse root, and dead coarse root. Every tissue has independent displayed,
storage, and transfer carbon and nitrogen operands.

For each tissue/element:

```text
preparation: S0 + X0 = Sprep + Xprep
deployment:  D0 + Xprep = D1 + X1
combined:    D0 + S0 + X0 = D1 + S1 + X1
```

No C:N ratio reconstructs nitrogen. No producer residual is authoritative.
The independent fixture uses deliberately non-stoichiometric C/N operands so a
derived-N alternative produces different bytes.
