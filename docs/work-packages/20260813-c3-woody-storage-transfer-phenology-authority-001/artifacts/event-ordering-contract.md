# Event Ordering Contract

Static: the accepted interval order is:

1. Freeze beginning shared C/N state.
2. Detect the phenology edge from beginning phase and GSI.
3. Prepare beginning storage once on `Dormant -> Onset`.
4. Deploy all six transfer pools to display with the admitted onset fraction.
5. Form offset, retranslocation, turnover, and mortality candidates.
6. Consume retranslocated N before external N demand.
7. Finalize E19 allocation.
8. Credit current growth to display/storage.
9. Reconstruct C/N closure.
10. Commit with all owners or none.

Current-interval E19 storage is ineligible for same-interval preparation.
Already-onset intervals deploy without preparing again. Threshold equality does
not create an upward crossing.
