# CQR34 Artifacts

This directory stores evidence for CQR34 summary accumulator complexity
closure. Generated LCOV and CRAP JSON outputs are retained with the package.

## Artifact Index

- `required-reading-map.md` - required and deferred reading for the package.
- `cqr34-quality-plan-report.md` - quality plan and baseline context.
- `cqr34-crap-before.md` - before CRAP metrics and target identity.
- `cqr34-crap-after.md` - after CRAP metrics and closure proof.
- `cqr34-coverage-closure.md` - before/after LCOV comparison.
- `cqr34-accumulator-equivalence.md` - accumulator behavior equivalence notes.
- `cqr34-implementation-and-test-evidence.md` - implementation and test
  evidence.
- `cqr34-line-count-governance-checklist.md` - line-count and governance
  checks.
- `owned-file-manifest.md` - package write-set manifest.
- `gate-results.md` - required command results.
- `review_agent_a.md` and `review_agent_b.md` - independent local reviews.
- `verification_agent_a.md` and `verification_agent_b.md` - independent local
  verification.
- `cqr34_disposition.md` - finding disposition.
- `worker-handoff.md` - package handoff and follow-up status.
- `lcov_before.info` and `lcov_after.info` - generated LCOV snapshots.
- `crap_before.json` and `crap_after.json` - generated CRAP snapshots.
