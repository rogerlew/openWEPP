# CAL-07E Artifacts

Evidence class: `Static + externally retrieved literature`

## Core results

- `literature-synthesis.md` answers the review questions and states the stop
  rule.
- `authority-disposition.md` records what is and is not authorized.
- `acquisition-needed.md` gives exact requests for inaccessible direct-site
  evidence.
- `source-register.csv` records 15 appraised sources or acquisition leads.
- `claim-evidence-matrix.csv` binds 15 claims to sources and limits.
- `phenocam-transition-product-audit.csv` compares the retained provisional
  standard-record `gcc_mean` and `gcc_90` transition rows.

## Protocol and communication

- `required-reading-map.md` freezes the local authority read before execution.
- `search-protocol.md` freezes search, admission, and stop rules.
- `../inputs/` retains the exact eight-row provisional PhenoCam source subset
  plus archive/member hashes and processing metadata.
- `figures/cal07e-evidence-authority-map.svg` is the accessible evidence plot.
- `figures/cal07e-evidence-authority-map.md` is its caption and ancillary
  information sidecar.
