- `attribution-and-recomputation.md`: primary result and decision.
- `protocol.md`: frozen protocol and bounded write-set amendments.
- `source-and-build-manifest.md`: exact identities and custody.
- `command-and-dependency-receipt.md`: command, environment, cut chronology, and
  external recovery details.
- `gate-results.md`: direct validation outcomes.
- `combined-instrumentation.patch`: complete P-to-Q observation-only patch.
- `raw/series-05` and `raw/analysis-final-cut3.json`: accepted timing evidence.
- `raw/recompute-trace-cut3` and `raw/recomputation-analysis.json`: accepted
  detailed recomputation evidence.
- `reproduction/`: collectors and portable analyzers.
- `review_agent_a.md`, `review_agent_b.md`, and `finding-disposition.md`:
  independent review and accepted corrections.
- `verification_agent_a.md`, `verification_agent_b.md`, and
  `final-disposition.md`: terminal closure evidence and executed-HOLD decision.
