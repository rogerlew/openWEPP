# Package author

Read the common guide, applicable write-path instructions and relevant sections
of the testing strategy. Kernel preparation also uses the kernel preparation
standard and applicable canonical science. Use active.md to locate current work;
search history only for identified dependencies.

Create package.md only. State objective, authorized scope/boundaries, acceptance,
selected checks and next action. A short instruction to execute this record is a
sufficient kickoff; no separate prompt or scaffold commit is required.
Use docs/work-packages/templates/package.md if helpful. Package scope and cadence
serve the user's objective; do not widen or merge packages to amortize paperwork.

Select independent review under the common guide. Freeze scientific thresholds,
data roles and result-bearing protocols before measurement. Routine file lists and
implementation steps may evolve inside authorized boundaries; reconcile the diff.
Acceptance must be achievable within scope or have a legitimate named boundary.
A required current gate cannot be deferred after it fails.

For kernel work preserve contract-first sequencing, typed guards, applicable
A0/A1/A3 and triggered science-obligations.md requirements. Solver work binds the
single-authority numerical standard: inventory touched reachable regimes, delete
superseded production paths and never extend historical fallback chains.
For conservation/output work include operand lineage and independent reconstruction
acceptance in the record. No parallel checklist document is required.
