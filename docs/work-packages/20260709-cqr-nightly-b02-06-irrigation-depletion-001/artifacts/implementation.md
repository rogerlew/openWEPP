# Implementation

The parser now uses private datver/header/static/period collection stages and
private exact error renderers. Furrow and sprinkler rows retain their dispatcher
but delegate their existing ordered arity/layout, value, compatibility, and
schedule branches to cohesive helpers. The header stores validated element count
directly, eliminating an unreachable private conversion result after its
preceding positive-itemp guard.

No grammar, datver policy, token position, field mapping, unit, warning, error,
topology, continuation, or fail-closed behavior changed.
