# Watershed CLI Publication Lineage

CLI options feed ordered preflight and runfile stages. Runfile validation flows
through required paths, hillslope modes, sidecar selection and fourteen output
paths. The supervisor validates pass inventory before contribution assembly;
typed topology/network state then dispatches and publishes through
`write_typed_publication_parquet_outputs` to real Parquet consumers.

Mechanical continuation stages preserve statement and first-error order.
Numeric helpers retain exact area conversion, five-class CRFRAC mapping,
manifest residual/carry limits and groundwater threshold authority. The full
CLI suite reads the emitted surfaces; private tests supply boundary evidence.
