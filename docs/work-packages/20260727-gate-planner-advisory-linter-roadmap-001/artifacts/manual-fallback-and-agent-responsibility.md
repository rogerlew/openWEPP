# Manual Fallback And Agent Responsibility

Status: `BINDING TARGET CONTRACT`

The manual route is the primary authority path and works without the linter.

1. Run `tools/agents/find-agents --for <intended-write-paths>` and read the
   returned instruction chain.
2. Read package intent, included/excluded scope, declared write set, required
   evidence, and the canonical testing strategy.
3. Establish the exact base, HEAD, index, tracked worktree changes, and
   untracked paths.
4. Map affected surfaces to focused tests, dependency consumers, science
   contracts, authority suites, typed guards, conservation/reconstruction
   checks, protected-data controls, and boundary-specific broad regression.
5. Run the selected commands directly from their documented working
   directories.
6. Record evidence class, exact command, source identity, result, retained
   output location, and any unmet requirement in the package.
7. Reconcile the terminal diff and disposition the package truthfully.

The agent may reject a false linter finding, add an omitted command, or decline
an excessive suggestion without asking the linter for permission. The
disposition cites the governing source and evidence.

If analysis is absent, malformed, partial, slow, contradictory, or internally
failed, continue with steps 1–7. Record a tool defect only when useful; never
create a prerequisite package or pause modeling merely to repair the linter.

An independently applicable requirement can still prevent closure. Escalate
only when its authority is genuinely ambiguous or required external state is
unavailable—not because the advisory tool failed.
