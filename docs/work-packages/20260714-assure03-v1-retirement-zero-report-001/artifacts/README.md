# ASSURE-03 Artifacts

Artifacts distinguish `Static:` inspection from `Ran:` execution and support
the package disposition. They are evidence, not replacement authority.

Required terminal records:

- exact v1 inventory and recovery verification;
- search and link classification;
- implementation and consumer-path evidence;
- gate and CRAP results;
- line-count governance;
- review A/B, finding disposition, verification A/B;
- final disposition and worker handoff.
