# External DAG Path Equivalence

Evidence class: `Static + Ran`

The CAL path-injection changes are limited to output-root operands. Focused
fixtures execute both injected layouts and compare successful readiness
membership, objective, recovery, and receipt bytes after allowing only the
declared absolute-path metadata fields. The same test also compares matched
`reconstruct` and `verify-reconstruct` failure behavior.

A successful small fixture for the production `reconstruct` binaries is not
currently structurally available. Both binaries require the production
`CAL04B03` identity: 9,261 candidates, 9 lanes, 36 years, 180 retained days per
year, and 932 observations. The required trace alone is
`4,320,812,180` bytes (`20 + 9261 * 9 * 6480 * 8`). Their parsers reject reduced
candidate, lane, year, day, or observation inventories before reconstruction.
Adding a fixture-only profile would change production code and is not
authorized by the current output-path-only equivalence correction.

Current evidence therefore remains:

- successful dual-layout readiness execution with 4,644 memberships and exact
  science/result comparisons;
- matched `reconstruct` and `verify-reconstruct` failure-path behavior;
- static one-purpose output-root injection diffs;
- the production CAL transition gate, when admitted and run by the external
  transaction adapter.

This artifact does not represent failure-path matching as successful science
equivalence. Final equivalence disposition remains subject to production
transition evidence or explicit reviewer acceptance of the structural bound.
