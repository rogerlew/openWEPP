# Fidelity Envelope

Status: queued placeholder.

Execution must predeclare, before tuning or implementation, the acceptance
surface for projected routing coefficients.

Candidate surfaces:

- single-OFE runoff magnitude and event timing versus legacy/default reference;
- single-OFE sediment magnitude versus legacy/default reference;
- MOFE runoff/sediment magnitude on selected coefficient-projected cases;
- active closure, positivity-clamp, DC01 no-double-feed, and routed hydrograph
  erosion-consumer gates;
- protected explicit-disable/legacy validation path identity;
- no tuning to one fixture; cohort-level ballpark acceptance only.

The package must distinguish fidelity adequacy from exact coefficient
equivalence. Projected coefficients may be acceptable if production outcomes
remain in a predeclared legacy-ballpark envelope.
