noncanonical parse, schema/version, outer and nested digest, identities,
lineage, scheduler, GSI, cursor, forcing, V10/V9, LSE-V2/V1, hydrology,
surface-liquid, soil, BGC, groundwater, erosion, ordering, omission, carry,
and reconstructed-cache failures. Every case captures complete canonical live
owner bytes and requires exact equality after rejection. The production host
also proves failed admission leaves the actual target consumer unchanged and
successful admission changes it with one assignment.
