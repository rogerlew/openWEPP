# Architecture Boundary

Status: `queued`

Evidence mode: `Static scaffold`

The intended architecture is one authoritative calculation, one production
state mutation, two exact linked compact ledgers, and one optional verbose
payload. Execution must replace this summary with a symbol-level producer,
outcome, ledger, handoff, capture-request, direct-runtime, formatter, writer,
and parser map before production edits.

The map must explicitly show that production-required Stage-3 values remain
available when verbose capture is disabled and that the capture request cannot
select a physical branch.
