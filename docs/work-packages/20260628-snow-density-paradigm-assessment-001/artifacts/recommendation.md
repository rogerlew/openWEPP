# Recommendation

Evidence class: Static.

## Decision

Recommend **Paradigm 1: climate-class snow-density specialization** as the next
snow-density candidate package.

Proceed with frost-attribution-threshold work in parallel using the current
`15` / `179` default as a bounded snow floor, but do not treat the snow-density
residual as exhausted for all time. The next density remediation attempt should
be a scoped opt-in class-aware bulk candidate before any multilayer rewrite.

## Decisive Reasoning

The remaining residual is dominated by a diffuse, split-sign
`seasonal_densification_trajectory` cluster (`9/15` robust fails). A single
global bulk curve has now failed multiple density/mass-removal variants, shallow
guarding, sublimation composition, and SNOBAL Stage B. The next candidate needs
regime divergence, not another global multiplier.

Paradigm 1 supplies that regime divergence with the smallest architecture
surface. Sturm 1995 provides independent snow classes from wind, precipitation,
and air temperature. Sturm 2010 provides class-specific density trajectory
evidence. The clean openWEPP form is **not** to adopt or tune the raw empirical
depth+DOY+class regression against local fixtures. The clean form is an opt-in
model that uses independently assigned class to select Anderson/SNOBAL-style
densification coefficients, then gates the result on the existing cross-SNOTEL
forcing-robust rubric.

Paradigm 2 is more physically complete, but it is too large for the next
evidence step. Multilayer density requires new snow-layer state, consumer
projection, conservation ledgers, performance evidence, and frost-interface
semantics. It is a credible escalation, not the first post-bulk experiment.

The baseline accept-floor option remains legitimate for the frost threshold:
10.3.21's read was mixed and found no single global snow lever. That is enough to
support a frost-attribution decision process with uncertainty carried forward.
It is not enough to call the density-structure question permanently closed when
a low-cost, independently authoritative regime-divergent candidate exists.

## Next Package

Scaffold a candidate package equivalent to:

`SNOWDENSITY-10.3.22 - climate-class density specialization candidate`

Scope:

- contract-first ADR-0028 candidate authority;
- opt-in selector only, with current no-env default and rollback preserved;
- independent snow-class assignment from Sturm 1995/NSIDC-0768 or weather-driver
  classification, never site identity;
- class-aware Anderson/SNOBAL coefficient specialization, not fixture-fitted raw
  regression;
- no fixture, public schema, density-cap, frost, or default activation change;
- whole-model conservation and cross-SNOTEL forcing-robust rubric as the gate.

Gate:

- promote only if the opt-in candidate beats the current default on the
  cross-SNOTEL forcing-robust rubric and does not create a new bidirectional
  persistence tail;
- hold or retire if the class-aware candidate is neutral/worse, class assignment
  is not independently authoritative, or conservation fails.

## Escalation Rule

If Paradigm 1 fails cleanly, the next density-structure discussion should move
to Paradigm 2 with an explicit architecture package for snow-layer state and
layer-to-scalar consumer projection. It should not continue adding global scalar
bulk multipliers to the exhausted family.
