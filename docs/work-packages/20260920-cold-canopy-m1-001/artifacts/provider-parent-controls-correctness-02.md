## Findings

1. **High — expected initial-phase payloads use the wrong scalar representation.** `m1_fixed_sequence_provider_controls.rs:434-450` copies `cycle["initial_phase_records"]` directly from `continuous-fixtures-draft01.json`; `:698-703` requires the emitted payload to equal those copied decimal JSON numbers. The closed `InitialPhaseV1` schema requires both `mass_kg_m2_tile_ground` and `enthalpy_j_m2_tile_ground` to be 16-character lowercase hexadecimal IEEE-754 binary64 strings. This control would reject a conforming implementation or bless a decimal-schema implementation, and its calendar-receipt oracle would then hash the wrong phase bytes. Build each expected phase row with the source occupancy ID and `format!("{:016x}", source_f64.to_bits())` for both physical values, then retain the full-payload and calendar-receipt comparisons.

2. **High — three adapter locators use a non-root RFC 6901 pointer.** `:425`, `:429`, and `:430` call `adapter_locator(..., "/")` for the complete exposure, topology, and controller output objects. RFC 6901's document-root pointer is the empty string; `/` selects a member whose key is the empty string. These rows therefore cannot select or authenticate the claimed complete output. Use `""` for those three roots and retain `/gsi` and `/destination` for the two member selections.

3. **High — the claimed dependency manifest is Cargo metadata, not adapter dependency authentication.** `ADAPTER_MANIFEST_PATH` at `:47` and `adapter_locator` at `:372-381` bind every extraction adapter to `crates/openwepp-hillslope-orchestrator/Cargo.toml`. That file does not enumerate the retained constructor/accessor dependency paths and SHA-256 values. Mutating the label at `:871-892` proves only that a field is checked; it cannot prove the adapter verified the bytes on which `endpoint_fixture`, the original structured projections, or the controller accessor depend. Supply a small frozen closed dependency manifest containing the actual source paths/hashes for the selected adapters, independently verify its bytes and every listed dependency, and bind that real manifest path/hash in the expected join rows and admission controls. The top-level `sources` array already contains its two mandatory entries; the contract permits additional adapter/manifest entries but does not make redundant top-level inventory a separate requirement.
