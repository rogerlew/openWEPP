assurance adoption, exact-diff reconciliation, and terminal verification for
the Stage 3 evaluation-shadow authority increment.

Work-package artifacts are evidence; canonical authority remains in
`SC-SNOWFREEZE-001`.

Key terminal records are:

- `gate-results.md` for exact-head focused, governance, and critical gates;
- `review-disposition.md` for every independent finding;
- `exact-diff-reconciliation.md` for the baseline-to-terminal path inventory;
- `disposition.md` for the package decision and successor holds; and
- `verification_agent_a.md` and `verification_agent_b.md` for terminal checks.
