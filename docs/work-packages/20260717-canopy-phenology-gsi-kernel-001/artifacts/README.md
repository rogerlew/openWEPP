# Evidence Map

Terminal evidence:

- `literature-and-intake.md`: equation, provenance, and existing-surface
  reconciliation.
- `contract-amendment.md`: contract identifiers and implementation mapping.
- `implementation.md`: source and test inventory.
- `focused-gates.md`: focused test/lint results.
- `heavy-gates.md`: full Rust, CRAP, and line-count results.
- `review-a.md`, `review-b.md`: independent implementation reviews.
- `disposition.md`: finding-by-finding producer disposition.
- `verification-a.md`, `verification-b.md`: initial terminal HOLDs.
- `verification-a-repeat.md`, `verification-b-repeat.md`: repeat HOLDs that
  caught the uniform-zero restart vector.
- `verification-a-final.md`, `verification-b-final.md`: final independent
  `PASS` verification of the nonuniform anchored-restart snapshot.
- `final-disposition.md`: exact terminal claim and follow-on integration handoff.
