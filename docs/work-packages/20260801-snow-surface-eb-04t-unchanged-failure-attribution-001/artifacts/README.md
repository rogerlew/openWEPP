# Artifact Inventory

Execution artifacts are generated by `tools/analyze_failures.py`. Figures live
under `artifacts/figures/` and each SVG has a same-stem Markdown sidecar.

Human-authored evidence includes process attribution, criterion fitness,
calibration readiness, gate results, two independent reviews, finding
disposition, two terminal verifications, exact-diff reconciliation, security,
line-count governance, final disposition, and worker handoff.
