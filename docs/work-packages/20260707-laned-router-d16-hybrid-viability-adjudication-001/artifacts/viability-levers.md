# Viability Levers

Status: EXECUTED. Evidence mode: Static + Ran.

## Assessment

The hybrid bones are good:

- It is stable and closes active day ledgers at machine scale.
- The H2637 hard case proves the method can win when the exact bare-skin
  evaluator covers the implicit work.
- The selector/plumbing surfaces the profile counters needed for rational
  promotion decisions.

The current selector is not viable as a default:

- It does not distinguish cheap exact bare-skin implicit work from expensive
  generic non-bare implicit map iteration.
- It has no no-harm fallback when predicted savings are poor.
- It still lacks production-facing fidelity/tolerance authority for active
  plain-vs-hybrid publication deltas.

## Ranked Levers

1. **Adaptive no-harm selector / preflight classifier.**
   - Predict, before routing a lane/day or run, whether eligible implicit work
     is mostly exact-bare-skin and whether expected step savings exceed
     generic solve overhead.
   - Route plain when the predicted profile resembles WA/N Idaho/MN generic
     map-cost cases.
   - Target acceptance: no selected member slower by more than a small named
     tolerance; aggregate selected suite faster than plain.
   - Likelihood: high for timing no-harm because the current evidence has a
     clear discriminator: H2637 `0` map evals wins; WA `98.2 M` map evals
     loses.

2. **Non-bare implicit solve-cost reduction.**
   - Replace generic nested map iteration for active vegetation/form/wave
     addends with a deterministic residual solve or additional exact/direct
     evaluators where algebraically justified.
   - WA is the prize case: `500560` implicit steps produce `98.2 M` map
     evaluations.
   - Must preserve `INV-OFEHYB-003` deterministic branch semantics and
     fail-closed guards.

3. **Fidelity/tolerance ratification with predeclared surfaces.**
   - Define promotion tolerances before further tuning: routed outlet,
     hydrograph timing/shape, HBP bytes or semantic deltas, pass sediment
     impacts, and closure surfaces.
   - Ratify across the selected cohort and H2637, not H2637 alone.
   - Without this, even a faster selector cannot be default-promoted.

4. **Switching/fidelity limiter.**
   - Consider stricter implicit eligibility for bins that still carry
     erosion-sensitive hydrograph shape or peak/runoff timing influence.
   - This lever targets the H2637 pass-sediment delta without discarding the
     entire hybrid concept.

5. **Tier-1 local numerics.**
   - Analytic celerity, cheaper friction evaluations, and `pow` reductions can
     help both plain and hybrid.
   - They are useful fleet optimizations, but they are not sufficient by
     themselves to solve the WA hybrid regression if generic implicit map
     iteration remains expensive.
