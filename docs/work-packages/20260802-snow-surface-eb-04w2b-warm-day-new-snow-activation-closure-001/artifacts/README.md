# EB-04W2B Artifacts

Evidence is labeled `Static:` or `Ran:`. The directory contains contract and
pre-implementation evidence, implementation/conservation proof, exact frozen
W2A rerun inputs and results, four accessible SVG figures with Markdown
sidecars, direct validation records, and independent review/verification.

The rerun JSON/CSV files are the machine-readable scientific record. Figures
are interpretive views and do not replace those retained values.
