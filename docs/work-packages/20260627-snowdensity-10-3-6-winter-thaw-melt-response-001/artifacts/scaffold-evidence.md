# Scaffold Evidence

Evidence mode: Static.

- Package directory created with `package.md`, active prompt, archived prompt
  directory, and artifacts directory.
- Package objective is bounded to diagnostic event-window evidence.
- Protected boundaries exclude production physics, defaults, fixtures, schemas,
  parser/CLI selectors, tuning, phase, density, frost, longwave, and rain-heat
  correction.
- Acceptance gates require committed JSON/Markdown event-window report artifacts.
