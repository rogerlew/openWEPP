# ASSURE-02 Artifacts

This directory records intake, research, pilot selection, real-evidence
prototype, review, verification, gate, migration, and final-disposition
evidence for ASSURE-02. These artifacts support canonical documentation; they
do not replace it and are not public scientific reports.

## Reading Order

1. `research-basis.md`, `pilot-candidate-inventory.md`, and
   `pilot-selection-decision.md` explain the research and pilot choice.
2. `prototype-linear-groundwater-reservoir-evaluation.md`,
   `groundwater-claim-evidence-matrix.md`, and
   `groundwater-current-tree-confirmation.md` demonstrate the proposed report
   architecture with real evidence.
3. `review-agent-a.md`, `review-agent-b.md`, `review-disposition.md`,
   `verification-agent-a.md`, and `verification-agent-b.md` preserve the dual
   internal coding-agent review and verification record.
4. `gate-results.md`, `line-count-governance.md`, `final-disposition.md`, and
   `worker-handoff.md` state the exact closure evidence, hold, and next decision.
