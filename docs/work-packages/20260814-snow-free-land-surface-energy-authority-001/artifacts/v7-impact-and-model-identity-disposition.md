# V7 Impact And Model Identity Disposition

V7 is immutable and remains valid for its completed default-off transaction.
The new coupled path changes two accepted V7 meanings: prescribed upward and
downward longwave become a reciprocal tile-column boundary, and occupancy-local
canopy-air residuals become one shared tile node containing ground sensible and
vapor flux. It therefore requires `OPENWEPP_C3_WOODY_V8`.

V8 imports every V7 equation not explicitly superseded. Its occupancy thermal
warm starts remain component-local, while canopy-air temperature/humidity move
to one tile state. Migration is deterministic only when all V7 occupancies in a
tile have bit-identical canopy-air temperature and humidity. Otherwise the
report names both unresolved tile fields; averaging is forbidden.

No V7 definition, fixture, digest, test claim, or implementation evidence is
rewritten.
