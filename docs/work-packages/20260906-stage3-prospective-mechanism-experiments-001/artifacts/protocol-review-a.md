## Implementation risks to resolve at the existing admission gates

The real oracle must independently enumerate evaluator class from coordinate
identity, authenticated topology/bounds and normative graph eligibility. Copying
an emitted class/stencil histogram and re-summing it would fail the approved
design. It must also detect omitted starts, missing completions and lost records
at authentic lifecycle boundaries; nonzero eligible counts alone do not prove
executed replay. Detailed record allocation must be absent in both primary
timing and memory arms, not merely excluded from the wall timer.

Runner CPU must use /proc/self/stat user+system deltas in recorded CLK_TCK units,
with field parsing that handles the parenthesized command name. Runtime memory
sampling must observe the actual direct child, not a Nix/build wrapper. wait4
peak is process lifetime evidence; it cannot substitute for an active-run peak.
These are source-verification targets under the protocol, not new acceptance
requirements or findings against unimplemented code.
