# Precipitation and Enthalpy Selection

Breakpoint storms retain exact half-open support and integrate overlap with
every child. Parent-hour mass is split equally only when finer support is absent.
Daily mass is never uniformly distributed. Harder--Pomeroy supplies liquid
temperature; parcel enthalpy is `m*4218*(T_K-273.15)`. Runon remains an accepted
upstream parcel, not meteorological precipitation.
