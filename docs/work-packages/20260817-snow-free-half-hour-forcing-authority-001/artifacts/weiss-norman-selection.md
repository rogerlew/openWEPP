# Weiss--Norman Selection

The complete original equations 1--12 and explicit ratio caps are transcribed
in `SC-SNOWFREEFORCING-001` and the independent calculator. Input is horizontal
global shortwave. Exact zero returns four zeros without air mass. Positive input
requires positive finite zenith cosine and pressure. Components must be finite,
nonnegative, and reconstruct the parent flux; no extra clipping is admitted.
