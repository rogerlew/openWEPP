# ASSURE-04A Artifacts

Artifacts distinguish `Static:` inspection from `Ran:` execution and support
the package disposition. They are evidence, not replacement authority.

Required records include intake/protected hashes, source-contract and field-
consumption maps, implementation/consumer evidence, gate/CRAP results, line-
count governance, delegated heavy-gate evidence, dual reviews, finding
disposition, dual verification, final disposition, and worker handoff.
