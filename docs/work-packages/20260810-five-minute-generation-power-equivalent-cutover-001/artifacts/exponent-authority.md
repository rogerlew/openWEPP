# Exponent Authority

Status: `complete — NO FIXED EXPONENT ADMITTED`

Evidence mode: `Static + Ran`

No candidate has the required equation-level authority for the production
generation-to-erosion response.

- `p=1` is the arithmetic-mean no-op control and provides no subhourly
  enrichment.
- `p=4/3` gives the smallest screened two-moment errors, but that exponent is
  not an exponent of the production generation-to-response equation. The
  production chain includes `q^0.303` width growth, an iterative Chezy depth,
  hydraulic-radius shear, Shields-number thresholds, Yalin class functions,
  `tcend`, `shear/tcend`, and a reciprocal deposition driver.
- `p=3/2` cannot be copied from `tcend=kt*shear^1.5`: `kt` is itself recomputed
  from Yalin capacity and shear, while shear is not generation rate.
- `p=2` has no contract-backed response authority and performs worse on the
  bounded driver screen.

The numerical acceptance gate independently rejects every candidate because
detachment-driver p95/max errors are 32.65%/33.54% or larger and deposition-
driver p95/max errors are 59.56%/59.56% or larger. The limits are 15% p95 and
30% maximum.

This is a prospective authority rejection, not calibration and not a Topanga
outcome decision. The exponent is not exposed as a parameter, and no result-
bearing Topanga file was opened. Erosion adoption is therefore
`NO_ADOPTION` for this package state.
