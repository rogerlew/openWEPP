Status: executed-complete after two dual-review rounds

gate authority, adopts it through ADR-0039, and records the bounded follow-up
needed to align repository guidance and automation. See [package.md](package.md).

remediated before terminal verification. This package changes authority only.

follow-up implementation package closes.

reviewers and renewed terminal verifiers pass the final tree after disposition
