## WB14 parent/child release boundary — 2026-08-23

Both independent reviews found that the prospective WB14 scalar/receipt state
machine is not yet the real coupled owner transaction. It does not stage and
atomically install surface storage, soil ingress/thermal, runoff, V11/LSE,
Stage 3, clock, provider, GSI, receipt-chain, and event owners, so child and
finalization rollback cannot yet prove the requested complete-owner bytes.

An in-envelope shortcut that relaxed the existing ingress continuation guard
was considered and rejected because it would expose short calls before parent
receipts and the complete owner join were enforced. The existing pre-physics
typed rejection remains. First lift step: install a typed WB14 parent adapter
inside the complete coupled candidate, consume its child receipts per accepted
slab, and prove dynamic Stage 3 cadence plus failure-injection rollback before
removing the guard.

The predecessor HOLD is preserved because the real V11 consumer is snow-free
and correctly rejects covered intervals, while no runner-owned sealed
48-support capability constructs the required covered physical inputs. This
successor is the authorized lift package. It may close only after the covered
consumer and runner/consumer path are real; a skeleton, producer-only helper,
or removed guard is not an acceptable lift.
