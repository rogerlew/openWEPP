# Observability Subsystem (`OBS`)

Canonical specification home for openWEPP observability.

## Scope

This subsystem defines:
- Typed debug intent contract.
- Kernel stimulation entrypoints for targeted execution.
- Structured trace/event schema.
- Deterministic replay-window interface.
- Migration/disposition from legacy ad-hoc `wepp_observe*` sidecars.
