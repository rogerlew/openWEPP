# Backlog

This directory captures concept-stage ideas that are intentionally **not**
ready for direct implementation.

Use backlog notes to record:
- motivation and expected value;
- governing constraints (science, contracts, provenance);
- minimal equations/abstractions;
- phased validation gates and promotion criteria;
- explicit open questions.

Promotion path:
1. Backlog concept note exists with clear constraints and falsifiable checks.
2. If prioritized, spin up a dated work package under `docs/work-packages/`.
3. If the change introduces new physics, route through openWEPP top-down
   science-contract authoring before default adoption.
